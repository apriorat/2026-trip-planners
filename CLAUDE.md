# Project notes for Claude

This repository holds planners for trips taken in 2026, one folder per trip.

## Folder naming rule
- Start folder names with the date, year first: `YYYYMM Place` (e.g. `202602 Taiwan`, `202605 Venice Padua`).
- Default to year + month only. Add the day (`YYYYMMDD Place`) when the exact date matters or when asked.
- After the date, use plain words separated by spaces.
- The user's request in the moment always overrides this default.

## Security
- Never commit real API keys or passwords into planner files. Keep placeholders such as `paste-your-key-here`.
